Design & Balancing Tool

- Custom characters with 4 unique abilities are created with custom in-editor tools
- Fast-paced PvP 'couch co-op' party game
- Direct minons and destroy the enemy's healing crystal

My most recent 'completed' project is Battle Mage Arena, built from scratch in UE5 Blueprint, with 3d assets from the marketplace. This started as a personal project but I adapted it into a tool to use for game design activties.

Using in-editor tools, students with no previous experience in game engines can build a character with 4 abilities, damage types, spell effects and stats. These are set up via various data structures in the details panel.

All character data is submitted to a master version of the game, allowing the characters to fight against each other. After some QA testing and balancing, all the characters are battled in a tournament!

This worked so well as an induction activity that I have used it multiple years for over 200 students.
